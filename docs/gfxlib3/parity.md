# gfxlib3 parity ledger

## Status meanings

| Status | Meaning |
| --- | --- |
| Not started | No gfxlib3 implementation exists. |
| Infrastructure | Supporting code exists, but the API is not usable end to end. |
| Implemented | The code path is complete enough to build and run. |
| Verified | Focused behavior tests pass. |
| Parity | Relevant gfxlib2, command-sweep, and QB tests pass. |

No item should skip directly from design work to Verified.
