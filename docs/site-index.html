FreeBASIC 1.20.4 Documentation

This is the documentation shelf for the FreeBASIC 1.20.4 packages hosted here. The manual and guides include the compiler, runtime, graphics, sound, serial, NuttX, platform, and package work completed since the 1.10.0 release.

Start with the online HTML manual or the 1.20.4 manual release page. The 1.10 to 1.20 history explains the full development sequence, including the untagged 1.20.2 baseline.
