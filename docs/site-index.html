FreeBASIC 1.20.6 Development Documentation

This documentation accompanies the FreeBASIC 1.20.6 development tree and the FBXL packages built from it. The manual and guides cover the compiler, runtime, graphics, sound, serial, NuttX, platform, and package work. Development continues, so package availability can differ by host.

Start with the online HTML manual or the 1.20.5 release notes. The 1.10 to 1.20 history explains the development sequence, including the untagged 1.20.2 baseline. The documentation index and source changelog cover the current 1.20.6 development tree.
