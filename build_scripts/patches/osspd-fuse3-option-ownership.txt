Ubuntu osspd 1.3.3-6 aborts in fuse_opt_parse when --adsp= or --mixer=
overrides an option field initialized with a string literal. FUSE 3 frees
the field's previous value before storing the parsed string. The same
initialization is present in the pinned upstream revision.

The patch leaves the three device-name fields NULL during parsing and
supplies omitted defaults afterwards. Explicit empty strings retain their
documented meaning. It changes neither the OSS protocol nor the ALSA backend.

Apply with patch -p1 from the extracted upstream directory. Qualification
uses a private binary and a task-owned CUSE device. No packaged binary or
system service is replaced.
