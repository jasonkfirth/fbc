dgGetTimeInMicrosenconds selects Windows QueryPerformanceCounter only for
_MSC_VER. The engine also supports _MINGW_32_VER and _MINGW_64_VER, but these
builds reach the end of this non-void function without returning a value.
The patch selects the existing Windows timer for these Windows targets.

Apply only to an exact private copy of the 3.13 source. Keep the original
license notices. Compile with -Werror=return-type and qualify the actual
resulting library before selecting it for an example.
